Getting Started with HostBuddy

Turn AI-generated code into real apps on your computer

v0.0.0

HostBuddy is your safe playground for AI-created applications. Copy code from ChatGPT, Claude, or any AI assistant, paste it here, and run it instantly. No coding knowledge required!

Create Your First App in 3 Steps

1

Get Code from AI

Ask ChatGPT, Claude, or Gemini to create an app for you. Copy the code they generate.

💡 Check the "AI Setup" tab for the best prompt to use!
↓
2

Create Project

Click "New Project" → Name your app → Paste the code in Step 6 → Click "Save"

📝 Optional: Add a description, icon, or attach image/CSS/JS files
↓
3

Run & Enjoy

Click the "Run" button on your project card. Your app opens in a new window!

🎉 That's it! Edit anytime by clicking the Edit button.

Powerful Features

📁

Organize with Folders

Create folders and drag-drop apps to organize your library.

  • Click + in sidebar to create folders
  • Drag apps onto folders to organize
  • Use Edit mode to rename/delete
🔄

Share & Import

Export apps as .hbproject files to share with others or back up.

  • Click Export on any project card
  • Share the .hbproject file with anyone
  • Import .hbproject files or drag them onto the window
✈️

Offline Mode

Download dependencies once for apps that work without internet.

  • Normal: Downloads each time (requires internet)
  • Offline: Downloads once, runs anywhere
🔒

Secure & Private

Everything stays on your computer. No cloud, no tracking.

  • All data stored locally
  • No internet required (except for dependencies)
  • Full control over your apps

MCP Server — Connect AI Tools Directly

HostBuddy runs a local Model Context Protocol (MCP) server that lets AI coding tools like Claude Code, Cursor, and Codex connect directly to your projects — so they can list, create, and update apps without you copying and pasting anything.

Checking server status…
Connection URL
http://localhost:6274/mcp
Add this URL to your AI tool's MCP configuration. HostBuddy must be running for the server to be available.

Configure Your AI Tool

⌨️ Claude Code / Claude Desktop

Add to your claude_desktop_config.json (Claude Desktop) or run the CLI command below (Claude Code):

claude_desktop_config.json
Claude Code CLI
🖥️ Cursor

Add to your project's .cursor/mcp.json file (or global Cursor MCP settings):

.cursor/mcp.json
🤖 OpenAI Codex / other tools

Any MCP-compatible tool that supports HTTP/Streamable HTTP transport can connect using:

Available MCP Tools:
  • get_documentation — Learn HostBuddy's code format and constraints
  • list_projects — List all your projects
  • get_project — Fetch a project's full code
  • get_project_for_ai — Get a project as an AI-ready markdown context
  • create_project — Create a new project with title and code
  • update_project — Update an existing project's code, title, or description
  • delete_project — Delete a project
Troubleshooting:
  • If the server shows an error, port 6274 may be in use — change it in Settings
  • The server only accepts connections from localhost for security
  • HostBuddy must be open and running for the MCP server to be available
  • After changing the port in Settings, restart HostBuddy for changes to take effect
